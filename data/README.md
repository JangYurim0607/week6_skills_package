# data

`roblox_games.csv` — A와 B가 똑같이 쓰는 입력 데이터.

- 출처: RoWatcher "The Most Popular Roblox Games Right Now, Ranked by Live Players" (2026-06-10 스냅샷). Grow a Garden의 누적 방문수는 ExitLag 장르 글에서 가져옴.
- `live_players_approx`는 글에 적힌 대략적인 동시 접속자 수이고, `lifetime_visits_b`는 누적 방문수(십억 단위)다. 빈 칸은 출처에 수치가 없다는 뜻이다.
- 검색량(search volume)은 수집하지 못했다. 그래서 키워드 분석은 "동시 접속자 = 수요"라는 대리 지표를 쓰며, 실제 검색량이 아니다.
- 스냅샷이라서 시간이 지나면 순위가 바뀐다. 최신 값은 RoWatcher에서 다시 확인해야 한다.
