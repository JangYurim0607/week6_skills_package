# 과제 명세 (A와 B 공통)

로블록스 게임 유튜브 쇼츠·틱톡 제작을 위한 **키워드 분석 리포트**와 **숏츠 스토리보드**를 만든다. 둘 다 PDF로 낸다.

## 입력

- `data/roblox_games.csv`: 인기 게임 16개의 장르, 동접, 누적 방문수 (RoWatcher 2026-06-10 스냅샷)
- `data/game_notes.md`: 게임 4개(Brookhaven RP, Adopt Me!, Steal a Brainrot, 99 Nights in the Forest)의 출처 있는 조사 노트

## 사실 규칙 (A와 B 모두 지킨다)

1. 게임 내용(규칙, 기능, 수치)은 `game_notes.md`와 CSV에 있는 것만 쓴다. 없는 내용을 사실처럼 쓰지 않는다.
2. 검색량, 조회수, 해시태그 사용량은 데이터가 없다. 지어내지 않고, 없다는 점을 리포트에 적는다.
3. 숫자를 자막이나 대사에 쓸 때는 어느 시점·출처 기준인지 같이 적는다.
4. 결과물에 `[입력]`, `TODO`, `OO` 같은 빈칸을 남기지 않는다. 직접 촬영해야 알 수 있는 내용을 말해야 하면, 그 내용을 대사로 쓰지 말고 "촬영 가이드"에 적는다.

## 결과물 1: 키워드 분석 리포트 (`keyword_analysis.pdf`)

A4 세로, 한국어, 4~6쪽. 포함할 것:

1. 한 장 요약: 무엇을 분석했고, 어떤 게임 3개를 왜 골랐는지
2. 데이터 범위와 한계 (검색량 없음 등)
3. 장르 묶음별 수요 비교 차트 1개 이상
4. 게임별 수요 표 (동접, 누적 방문수, 장르)
5. 게임별 키워드 후보 목록 (한국어와 영어, 검색 의도, 숏츠 앵글). 후보는 검증된 값이 아니라는 표시
6. 선택한 3개 게임의 선정 근거와 제작 우선순위
7. 다음 단계 (검색량을 확인할 방법 등)

## 결과물 2: 숏츠 스토리보드 (`storyboard.pdf`)

3편(게임 3개, 편당 25~40초, 세로 9:16)을 한 파일로. 포함할 것:

1. 표지 겸 개요: 3편의 제목, 길이, 앵글, 올릴 플랫폼
2. 편마다 샷 목록 (6~8샷). 샷마다 다음을 적는다.
   - 샷 번호와 시간 구간
   - 화면 구성: 9:16 프레임 스케치(도형과 글자로 그린 간단한 그림이어도 된다)
   - 촬영할 장면 설명
   - 한국어 내레이션 (그대로 읽을 수 있는 문장)
   - 화면 자막
   - 효과음/BGM 메모
3. 편마다 첫 3초 훅 설명, 끝 장면(CTA 또는 다음 편 예고)
4. 촬영 가이드: 플레이 영상에서 직접 확인하고 녹화해야 할 것 (대사에는 쓰지 않은 것)
5. 내레이션 합계 글자 수로 추정한 길이 (초당 5.5~6.5자 기준, 추정이라는 표시)

## 코드와 PDF 도구

- 분석에 쓴 코드는 직접 짜서 실행한다. 차트는 matplotlib, PDF는 HTML을 Chromium(Playwright)으로 인쇄하는 방식이나 reportlab 중 편한 것을 쓴다.
- 한글은 `Noto Sans CJK JP` 폰트로 렌더링한다(한글 글리프 포함). PDF를 이미지로 변환해 글자가 깨지지 않았는지 직접 확인한다.
- PDF 도구 선택은 A와 B 모두 자유다. 비교 대상은 "스킬 패키지(아래 B 프롬프트)"의 유무다.
