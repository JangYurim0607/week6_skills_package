# roblox-shorts-ko

영어 기준 슬롭 제거 스킬은 한국어에서 효과가 약하다. 이 스킬은 한국어 숏츠 대본에 맞춘 규칙과 검사 스크립트를 준다.

## 입력과 출력

- 입력: 게임명, 장르, 키워드 후보(`keywords.csv`), 앵글 한 줄
- 출력: 25~40초 분량 대본 1편. 문장마다 `[화면: ...]` 표시, 훅 후보 3개와 선택 이유 한 줄

## 톤

1. 친구한테 말하듯 쓴다. 기본은 해요체와 반말 섞기("이거 모르면 손해예요", "진짜 이게 되네").
2. 한 문장은 25자 안팎. 한 번에 한 가지만 말한다.
3. 첫 3초(첫 문장)에 결과나 궁금증을 던진다. 인사, 채널 소개, 게임 설명으로 시작하지 않는다.
4. 숫자는 대본에 근거가 있을 때만 쓴다. 지어내지 않는다. 근거 없는 수치는 `[수치 확인 필요]`로 둔다.
5. 마지막 문장은 행동 하나만 요청한다(예: "다음 편은 버그 모음이에요").

## 로블록스 용어

로블록스, 로벅스, 서버, 맵, 아이템, 펫, 레어, 보스, 리스폰, 스폰, 버그, 업데이트, 챌린지. 게임 고유 이름은 영문 표기를 그대로 쓴다(Brookhaven RP, Blox Fruits 등). 직역해서 새 용어를 만들지 않는다.

## 한국어 슬롭 패턴 (금지)

- 보고서투 시작: "~에 대해 알아보겠습니다", "오늘은 ~를 소개해 드리겠습니다"
- 접속어 남발: "결론적으로", "또한", "더불어", "이처럼"
- 빈 형용사: "다양한", "다채로운", "독특한", "특별한 경험"
- 번역투: "~하는 것이 가능합니다", "~라는 점에서 의미가 있습니다", "~뿐만 아니라 ~까지"
- 광고 멘트: "지금 바로 확인해 보세요", "놓치지 마세요", "꼭 한번 해보세요"
- "여러분"으로 호명, 이모지 줄줄이, 느낌표 남발
- "X가 아니라 Y입니다" 식 반전 문형 반복

전체 목록과 규칙은 `scripts/ko_slopcheck.py`의 `BANNED`에 있다. 대본을 쓴 뒤 반드시 실행하고 점수를 남긴다.

```bash
python3 scripts/ko_slopcheck.py script.md
```

## 절차

1. 앵글과 키워드를 받는다.
2. 훅 3개를 쓴다. 영어 훅 스킬(yt-script)의 공식 목록을 참고해 구조만 가져오고 문장은 한국어로 새로 쓴다.
3. 본문을 쓴다. 한 비트에 한 화면.
4. `ko_slopcheck.py`를 돌려 금지 패턴을 고친다.
5. 영어 슬롭 스킬의 원칙(구체성, 리듬 변화, 불필요한 헤지 삭제)을 한국어에 맞게 적용해 마지막으로 읽어 본다.
