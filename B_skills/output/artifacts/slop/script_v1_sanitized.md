# 편 1. Brookhaven RP

### 내레이션
- 직업 아이콘이 80개 넘는데 월급은 없어요.
- Brookhaven RP는 도시에서 역할놀이를 하는 무료 게임이고, 평소 동접이 40만에서 50만이에요.
- 퀘스트도 없고 레벨도 없고 게임 속 돈도 없어서, 직업은 그냥 장식이에요.
- 대신 집과 테마 장소가 115개 넘게 있고, 룸메이트와 같이 꾸밀 수 있어요.
- 탈것은 190개 넘게 있고 무료도 24개 넘어요. 유료는 275에서 799 로벅스예요.
- 다만 목표가 없어서 새로움이 지나면 밋밋하다는 평가도 있어요.
- 결론적으로 이 게임은 목표가 아니라 놀이터예요. 다음 편은 Adopt Me! 펫 합치기예요.

### 자막
- Brookhaven RP / 일하면 얼마 줄까?
- 역할놀이 무료 게임 / 동접 40만~50만
- 퀘스트 X 레벨 X 돈 X
- 집·장소 115개 이상
- 탈것 190개 이상, 무료 24개 이상
- 약점: 목표가 없다
- 다음 편: Adopt Me!

# 편 2. Adopt Me!

### 내레이션
- 같은 펫 네 마리를 합치면 뭐가 되는지 알아요?
- Adopt Me!는 알에서 펫을 부화시키는 게임이에요. 알 종류마다 나오는 펫이 달라요.
- 펫은 희귀도가 5단계고, 여러 성장 단계를 거쳐요.
- 다 자란 같은 종류 펫 4마리를 합치면 네온 펫이 돼요.
- 네온 펫 4마리를 합치면 메가 네온 펫이 되고요.
- 펫은 서로 교환할 수 있는데, 사기가 많아서 2020년에 거래 면허와 사기 경고가 생겼어요.
- 다음 편에서는 99 Nights in the Forest를 소개해 드릴게요.

### 자막
- 펫 합성의 결과는?
- 알마다 나오는 펫이 달라요
- 희귀도 5단계
- 펫 4마리 → 네온
- 네온 4마리 → 메가 네온
- 2020년 거래 면허·사기 경고
- 다음 편: 99 Nights

# 편 3. 99 Nights in the Forest

### 내레이션
- 99번의 밤 모닥불, 뭘 챙겨야 지킬까요?
- 숲에서 깨어나 99번의 밤을 버티면 구조되는 게임이에요. 밤이 갈수록 적도 강해져요.
- 낮에는 나무와 음식, 제작 재료를 모으고 건물을 찾고 생존자를 구해요.
- 너무 멀리 가면 밤에 갇힐 수 있어서, 저녁에는 캠프로 돌아와 방어를 보강해요.
- 모닥불은 밤마다 꺼지지 않게 해야 하는데, 연료가 나무예요. 나가기 전에 여분을 챙기세요.
- 밤이 되면 생물이 공격해요. 뒤로 갈수록 무리가 커지고 빨라지고 특수 능력을 가진 적도 나와요.
- 멀티로 하면 역할을 나눠서 더 수월해요. 혼자 할지 멀티로 할지 댓글로 알려 주세요.

### 자막
- 낮에 챙길 것?
- 99번 버티면 구조
- 낮 = 모으기
- 저녁 = 캠프 복귀
- 모닥불 연료 = 나무
- 밤 = 적 습격
- 솔로? 멀티?
