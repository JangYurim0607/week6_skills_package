# A vs B 비교

같은 입력(`data/roblox_games.csv`), 같은 과제, 같은 모델로 A(스킬 없음)와 B(스킬 패키지)를 각각 한 번씩 돌렸다. 한 번씩만 돌린 결과라서 통계적 결론은 아니고, 이 한 번의 차이를 정리한 것이다.

## 숫자로 본 차이

| 항목 | A (스킬 없음) | B (스킬 패키지) | 비고 |
|---|---|---|---|
| 한국어 슬롭 점수, 대사만 (`ko_slopcheck.py`, 낮을수록 좋음) | 8 | 0 | A는 "여러분" 1건 적중 |
| 평균 문장 길이(대사) | 22.6자 | 21.6자 | 거의 같음 |
| 대본 편수, 형식 | 3편, 시간표 표 | 3편, 비트 6개 + `[화면]` 지시 | |
| CSV에 없는 게임 플레이 묘사 | 있음(예: 99 Nights의 낮 자원 모으기와 불 지키기, Dress To Impress 점수 규칙) | 없음 | A는 "촬영 전에 확인하세요"라고 한 줄 경고 |
| 촬영 후에 채워야 하는 빈칸 | 0개 | 6개 | 지어내지 않은 대가 |
| 훅 후보 | 대본마다 1개 | 대본마다 5개를 채점해 2개 비교 | |
| 키워드 분석 길이 | 99줄 | 124줄 | |
| 분석 코드 | `A_baseline/code/analyze.py` 71줄 | `B_skills/scripts/` 3개 파일 | |

## 눈에 띄는 차이

- **지어내기**: A는 CSV에 없는 게임 내용을 대사로 썼다(밤에 불이 꺼지면 끝이라는 식의 서술). B는 숫자와 장르만 쓰고 모르는 부분은 `[촬영 후 입력]`으로 비웠다. 이 차이는 `yt-script`와 `anti-ai-slop`의 "지어내지 않는다" 규칙에서 왔다고 B의 사용 기록에 적혀 있다.
- **말투**: A는 "~합니다" 체와 "여러분", "댓글로 알려주세요" 같은 광고 멘트가 섞였다. B는 `roblox-shorts-ko`의 톤 규칙과 금지 목록을 보고 써서 해요체 중심이다.
- **구조**: B는 훅 5개 채점, 비트 6개, 화면 지시, 자막 길이 제한, 루프 메모가 있다. A는 시간표 표 하나다.
- **분석 문서**: 둘 다 검색량이 없다는 점을 먼저 밝혔다. B는 검색 의도 분류의 빈틈(navigational 없음)과 검증 못한 부분을 문서에 적었다.

## 정직하게 적어 두는 한계

- **B의 대본은 덜 완성돼 보인다.** 빈칸 6개가 있고 세 편이 같은 골격("6월 10일 기준 N위, 동접, 장르 표기")이라 틀에 박혀 보인다. B 사용 기록에도 이 문제가 남은 것으로 적혀 있다.
- **영어 슬롭 도구는 한국어에서 거의 쓸모가 없었다.** `anti-ai-slop/scripts/slopcheck.py`는 일부러 나쁘게 쓴 한국어 문단에도 100점을 줬다. `hookscore.py`는 한글을 단어로 세지 못해서 점수가 영문 게임명과 숫자에 좌우됐다. 그래서 한국어 검사기(`ko_slopcheck.py`)를 직접 만들어 넣었다.
- **`ko_slopcheck.py` 점수는 B에 유리하게 나올 수밖에 없다.** B는 이 검사기의 금지 목록을 보고 썼다. 0점은 금지 문자열이 없다는 뜻이지 대본이 더 재미있다는 뜻이 아니다.
- **실행하지 못한 것**: `anti-ai-slop`의 `grade.py`(외부 모델 패널)와 `detect.py`, 독립 검토자 단계는 API 키와 환경 제약 때문에 못 했다.
- **한 번씩만 돌렸다.** 같은 조건으로 여러 번 돌리면 A도 "여러분"을 안 쓰는 날이 있을 수 있다.
- **영상 성과는 재지 않았다.** 어느 쪽이 조회수가 더 나올지는 이 비교로 알 수 없다.

## 증빙 파일
