# 로블록스 숏츠 대본 3편 (각 25~40초)

선정 근거는 `keyword_analysis.md` 5번 항목 참고. 수치는 rowatcher 2026-06-10 스냅샷 기준이며, 게임 내 구체적인 팁·연출은 일반적인 플레이 내용 기준으로 썼으니 촬영 전에 직접 확인하세요.

---

## 1. Steal a Brainrot (약 30초)

**키워드:** 브레인롯 훔치기, 스틸 어 브레인롯, 로블록스 밈
**제목 안:** 남의 브레인롯 훔치는 게임이 누적 698억 방문?

| 시간 | 화면 | 대사 |
|---|---|---|
| 0~3초 | 내 기지에서 누가 캐릭터를 가져가는 장면 | "내 브레인롯, 방금 털렸습니다." |
| 3~10초 | 게임 타이틀과 플레이 장면 | "이 게임 규칙은 단순해요. 브레인롯을 모으고, 남의 걸 훔칩니다." |
| 10~20초 | 훔쳐서 도망가는 장면 | "훔치는 건 쉬운데 들고 내 기지까지 가는 게 진짜 승부예요." |
| 20~27초 | 자막: 누적 방문 69.8B / 동접 15만+ | "누적 방문 698억, 지금 동시접속도 15만이 넘어요." |
| 27~30초 | 엔딩 | "여러분은 지킬래요, 훔칠래요? 댓글로 알려주세요." |

## 2. 99 Nights in the Forest (약 35초)

**키워드:** 숲속의 99일 밤, 99일 밤 공포, 로블록스 공포게임
**제목 안:** 숲에서 99일 버티기, 가능할까?

| 시간 | 화면 | 대사 |
|---|---|---|
| 0~3초 | 어두운 숲, 정적 | "99일 동안 이 숲에서 살아남아야 합니다." |
| 3~12초 | 낮에 자원 모으는 장면 | "낮에는 나무를 모으고 불을 지킬 준비를 해요." |
| 12~24초 | 밤이 되고 긴장되는 연출 | "문제는 밤이에요. 불이 꺼지면 끝이라는 마음으로 버텨야 합니다." |
| 24~32초 | 자막: 동접 285,000 (4위) | "지금 동시접속 28만 명, 로블록스 전체 4위예요." |
| 32~35초 | 엔딩 | "혼자는 무서우니까 친구랑 같이 들어가 보세요." |

## 3. Dress To Impress (약 28초)

**키워드:** 드레스 투 임프레스, 로블록스 패션, 로블록스 코디
**제목 안:** 로블록스에서 패션쇼 우승하는 법

| 시간 | 화면 | 대사 |
|---|---|---|
| 0~3초 | 런웨이 위 캐릭터 | "로블록스에서 패션쇼가 열립니다." |
| 3~12초 | 테마 발표, 옷 고르는 장면 | "주제가 나오면 제한 시간 안에 옷을 골라 코디를 완성해요." |
| 12~21초 | 런웨이 워킹, 점수 장면 | "다른 플레이어가 점수를 매기고, 가장 높은 점수를 받으면 우승입니다." |
| 21~25초 | 자막: 누적 방문 10.3B | "누적 방문은 100억 이상이에요." |
| 25~28초 | 엔딩 | "오늘의 주제로 코디해 볼 테니 점수 매겨주세요." |
