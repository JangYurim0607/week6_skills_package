제작 순서와 선정 이유

키워드 분석 리포트의 우선순위(Brookhaven RP, 99 Nights in the Forest, Steal a Brainrot) 순서입니다. 선정 근거는 동접과 누적 방문수를 수요의 대리 지표로 쓴 것이며, 검색량은 확인하지 못했습니다.

읽는 법

  • 각 편은 샷 6~8개로 구성되고, 샷마다 시간 구간, 9:16 프레임 스케치, 촬영할 장면, 내레이션, 화면 자막, 효과음/BGM을 적었습니다.
  • 프레임 스케치는 도형과 글자로 그린 구도 메모이며 실제 게임 화면이 아닙니다.
  • 자막이나 대사에 쓴 숫자는 기준 시점·출처를 자막 아래 "기준"으로 함께 적었습니다.
  • 직접 촬영해서 확인해야 하는 내용은 대사에 쓰지 않고, 각 편 마지막의 "촬영 가이드"에 모았습니다.
  • 길이 추정은 내레이션 글자 수(공백 제외, 문장부호 포함)를 초당 5.5~6.5자로 나눈 추정값이며, 편집 후 실제 길이는 달라질 수 있습니다. 각 샷의 시간 구간은 초당 6자 기준의 계획값입니다.
게임 내용은 조사 노트와 CSV에 있는 것만 사용했고, 검색량·조회수·해시태그 사용량은 데이터가 없어 쓰지 않았습니다.

첫 3초 훅

첫 3초: 내 기지의 브레인롯을 다른 플레이어가 가져가는 순간을 보여 주며 "내 브레인롯, 남이 훔쳐 갈 수 있어요"라고 말한다. 잃는 장면을 먼저 보여 주는 훅.

끝 장면 (CTA / 다음 편 예고)

끝 장면: 미끼를 앞에, 값진 것을 뒤에 둔 완성된 기지 배치 컷. 댓글 유도(뭘 미끼로 둘지)와 다음에 볼 게임을 고르는 질문 자막.

촬영 가이드 (직접 확인하고 녹화할 것, 대사에는 쓰지 않음)

  • 훔치기 장면은 촬영용 계정 둘로 직접 연출해 녹화한다(다른 사람의 기지를 무단으로 쓰지 않는다).
  • 훔치기 게이지가 화면 어디에 어떻게 표시되는지, 방해받았을 때 초기화되는 모습을 확인하고 녹화한다.
  • 방어 4종(레이저 장벽, 슬롯 잠금, NPC 경비, 임시 방어막)이 실제 화면에서 어떻게 보이는지 하나씩 확인한다.
  • 리버스 화면에서 보상이 어떻게 표시되는지 확인한다. 희귀도별 수익 수치는 가이드 안에서도 어긋난다고 해서 대사에 쓰지 않았으므로, 필요하면 촬영 화면에서 직접 확인한 값만 자막에 쓰고 촬영일을 적는다.
  • 가이드의 "2026년 7월판" 공략이 현재 게임 버전과 같은지 방어 항목이 화면에 있는지로 확인한다.
